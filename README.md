# Proyecto Final · Sistemas Operativos

**Grupo 1 | Universidad del Valle · Sede Yumbo**

## Descripción del proyecto

Este proyecto consiste en la implementación y configuración de dos máquinas virtuales con sistemas operativos Linux mediante VirtualBox. Además, se desarrolla una imagen personalizada utilizando Docker, se publica en Docker Hub y se realiza su despliegue en Kubernetes.

El desarrollo del proyecto permite poner en práctica los conocimientos adquiridos durante el curso de Sistemas Operativos, trabajando con máquinas virtuales, administración de sistemas, servicios, contenedores y herramientas de despliegue.

## Objetivo general

Implementar un entorno de trabajo basado en sistemas operativos Linux mediante máquinas virtuales y herramientas de virtualización y contenedores, aplicando conocimientos de instalación, configuración, administración, seguridad y despliegue de servicios.

## Herramientas y tecnologías

- VirtualBox: herramienta utilizada para crear y ejecutar las máquinas virtuales.
- Kubuntu: distribución Linux seleccionada para la máquina virtual con entorno gráfico.
- Debian: distribución Linux seleccionada para la máquina virtual de consola.
- Ubuntu: distribución seleccionada como imagen base para Docker.
- Docker: herramienta utilizada para crear y administrar contenedores.
- Docker Hub: plataforma para publicar y almacenar la imagen creada.
- Kubernetes: herramienta utilizada para realizar el despliegue de la aplicación.
