# Proyecto Final · Sistemas Operativos

**Grupo 1 | Universidad del Valle · Sede Yumbo**

## Descripción del proyecto

Este proyecto consiste en la implementación y configuración de dos máquinas virtuales con sistemas operativos Linux mediante VirtualBox. Además, se desarrolla una imagen personalizada utilizando Docker, se publica en Docker Hub y se realiza su despliegue en Kubernetes.

El desarrollo del proyecto permite poner en práctica los conocimientos adquiridos durante el curso de Sistemas Operativos, trabajando con máquinas virtuales, administración de sistemas, servicios, contenedores y herramientas de despliegue.
